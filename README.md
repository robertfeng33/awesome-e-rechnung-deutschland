## Die gesetzliche Anforderung verstehen: Was sind XRechnung und ZUGFeRD?

Um zu verstehen, warum ein Spezialwerkzeug wie Billfix so wertvoll ist, lohnt sich ein kurzer Blick auf die technischen Vorgaben der neuen E-Rechnungspflicht.

Ein einfaches PDF-Dokument ist für das menschliche Auge perfekt lesbar, für Computerprogramme aber nur schwer automatisch auszuwerten. Die E-Rechnungspflicht verlangt daher Formate, die Maschinen direkt verarbeiten können.

Dabei haben sich zwei Standards etabliert:

Erstens: Die **XRechnung**. Sie besteht aus einer rein strukturierten XML-Datei. Für den Menschen sieht das aus wie ein chaotischer Salat aus Code und Tags, für Buchhaltungssysteme von Konzernen und Behörden ist es jedoch die perfekte, fehlerfreie Datengrundlage.

Zweitens: Das **ZUGFeRD-Format**. Dies ist ein cleveres Hybrid-Format. Es kombiniert eine visuell ansprechende PDF-Datei (die Sie wie gewohnt ausdrucken oder am Bildschirm lesen können) mit einer unsichtbar eingebetteten XML-Datei für die automatische Weiterverarbeitung.

**Billfix für Windows** beherrscht beide Formate aus dem Stegreif. Sie müssen kein IT-Spezialist sein und keine komplexen Datenstrukturen verstehen. Sie geben Ihre Rechnungsdaten in eine gewohnte, übersichtliche Eingabemaske ein – Billfix kümmert sich im Hintergrund völlig automatisch um die korrekte, normgerechte Dateierstellung.
